# signing

Local working directory for Developer ID signing material. Everything here is
gitignored except this file.

Expected contents while setting up:

- `Bifrost.certSigningRequest` — generated by Keychain Access
- `developerID_application.cer` — downloaded from developer.apple.com
- `DeveloperID_Application.p12` — the cert plus its private key, exported from
  Keychain Access, used to create the `DEVELOPER_ID_P12_BASE64` GitHub secret

The `.p12` and its password are the keys to signing releases as Fosh Labs OU.
Move them to a password manager once the GitHub secret is set; this folder is a
staging area, not storage.
